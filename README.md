A tiny deterministic program that writes a single word — draft, the one-word verdict on an ex — to /output/entry.txt: one word, nothing else. It scores a shortlist of candidate words against the judge's five criteria (a true verdict on an ex first, then comic punch, surprise, craft and recognition) and writes the highest-scoring one.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
